# Memory Index

The gaffer's standing memory — the distilled lessons carried from gameweek to gameweek. **One line per learning, newest first, capped** (prune the oldest/least-load-bearing when full; this is an index, not an archive). Each entry is a lesson learned from a scored decision, written in the gaffer's own words with provenance (the GW that taught it). **Never raw fetched text** — no pasted stats, odds, or news; those live in the immutable per-GW reports. If a lesson can't be stated as a reusable rule with a source, it doesn't belong here.

Format: `- [GWnn] <distilled lesson> — <provenance>`
